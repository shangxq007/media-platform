# OpenAPI HTTP Contract Authority

OpenAPI **3.1.0** is the authoritative REST transport contract for this
repository. Springdoc OpenAPI `3.0.2` is the runtime/toolchain dependency and
the checked-in export reports `openapi: 3.1.0`; the contract is not downgraded
to OpenAPI 3.0 for historical compatibility.

## One authority and its projections

| Artifact | Role | Editing rule |
|---|---|---|
| `docs/api/openapi-preview-current.json` | Checked-in generated export from runtime `/v3/api-docs` | Generated; replace only by the export command |
| `/v3/api-docs` and `/v3/api-docs/{group}` | Runtime observation | Generated by controllers, DTOs, annotations, and security configuration |
| `contracts/http/media-api/openapi.base.yaml` | Previous accepted compatibility baseline fixture | Change only through contract review |
| `contracts/http/media-api/openapi.candidate.yaml` | Candidate compatibility fixture | Derived from the proposed contract change |
| `contracts/http/media-api/openapi.breaking.yaml` | Negative test fixture | Must remain intentionally breaking |

The base, candidate, and negative files are compatibility-test inputs, not a
second manually maintained REST authority. GraphQL, MCP, domain events, and
internal worker protocols remain separate contracts with their own owners.

## Generation rule

Export the runtime document and record the runtime URL and commit in the
validation report:

```bash
bash scripts/api/export-openapi.sh \
  "${MEDIA_PLATFORM_API_URL:-http://localhost:8080}" \
  docs/api/openapi-preview-current.json
```

The export must parse as JSON, declare `openapi: 3.1.0`, and contain stable
`operationId` values. Controllers and DTO/schema definitions are the executable
implementation; authentication, tenant/workspace scope, error responses,
idempotency, retry, concurrency, and deprecation semantics must be reviewed
against the generated artifact before acceptance.

## Compatibility gate

Install the pinned `oasdiff` v1.28.0 binary when it is absent, then run:

```bash
bash scripts/check-api-contract-governance.sh
```

The gate must run the positive base→candidate comparison and the negative
base→breaking fixture. If the binary or runtime is unavailable, the result is
`NOT_RUN` with the missing prerequisite; a partial substitute is not a pass.

## Current verification state

The checked-in artifact is OpenAPI 3.1.0. Runtime export, generated-artifact
freshness, and oasdiff execution are recorded separately in the governance
validation report so cached evidence cannot be mistaken for a fresh check.
