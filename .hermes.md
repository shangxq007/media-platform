## Toolchain

- Java 25 (Gradle toolchain), Spring Boot 4.0.4, Gradle 9.1.0 through the committed wrapper.
- Build: `./gradlew --no-daemon compileJava`
- Test compile: `./gradlew --no-daemon compileTestJava`
- Boot jar: `./gradlew --no-daemon :platform-app:bootJar`
- Database tests: PostgreSQL 18 through the controlled launcher (`scripts/test-infra`,
  `CONTROLLED_LAUNCH_REQUIRED`). H2 is prohibited; never add it as a dependency.

## Verification

Use [`scripts/dev/verify`](scripts/dev/verify) instead of ad-hoc command discovery:

```sh
python3 scripts/dev/verify preflight --level l1   # fast environment gate
python3 scripts/dev/verify l1 --module <module>   # affected unit/contract tests
python3 scripts/dev/verify guards                 # architecture + instruction + jOOQ + OIDC guards
```

L2/L3 definitions and evidence rules are in [`docs/dev/verify.md`](docs/dev/verify.md). Do not start
L3 when preflight reports a blocker; repeated retries on an unchanged blocked environment waste time.

## Working style

- Single writing agent per worktree; one task branch per worktree.
- Report progress in Chinese during long sessions; surface blockers early with exact commands.
- Prefer the narrowest relevant test first, then the affected module, then the broader gate.
- Do not weaken or relabel tests to make a gate pass; record real failures.
- Remote mutations (push, deploy, release) require explicit owner authorization.
