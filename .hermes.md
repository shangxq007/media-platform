# Media Platform — Project Rules

## Build & Test
- Java 25, Spring Boot 4.0.4, Gradle 9.1.0
- Build: `./gradlew compileJava --no-daemon`
- Test compile: `./gradlew compileTestJava --no-daemon`
- Boot JAR: `./gradlew :platform-app:bootJar --no-daemon`
- Architecture guard: `bash scripts/check-architecture-drift.sh` (32 checks)
- Testcontainers PostgreSQL for all tests
- H2 database is PROHIBITED — never introduce H2 dependencies

## Architecture
- 37 Gradle submodules
- Flyway V1-V4, canonical doc: `docs/database/flyway-migration-baseline.md`
- No new Flyway migrations without explicit approval
- Provider ID `ffmpeg` is canonical, `FFmpegRenderProvider` is implementation class name
- RenderJob = one execution attempt, Product = canonical communication object
